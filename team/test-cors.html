🔧 CORS Test Suite

Test CORS configuration for Railway email API

📋 What This Tests

  • Test 1: Sends an OPTIONS request to verify CORS headers are present
  • Test 2: Tests the health endpoint to verify Railway is running
  • Test 3: Sends a POST request to /send-email to test the actual endpoint (will fail due to missing data, but tests CORS)

✅ Expected Results

  • All tests should show CORS headers including Access-Control-Allow-Origin
  • No CORS errors should appear in browser console
  • Status codes: 204 (OPTIONS), 200 (health), 400 (POST with missing data)

❌ If Tests Fail

  • Clear browser cache (Ctrl+Shift+Del)
  • Try in incognito/private window
  • Check Railway deployment status
  • Check browser console for detailed error messages
