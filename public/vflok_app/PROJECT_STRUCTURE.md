## 🔧 Installation Steps

### For You (The Developer)

1. **Copy the dashboard HTML**:
   ```bash
   copy ..\vflok_dashboard.html renderer\index_base.html
   ```

2. **Create the database**:
   ```r
   # In R/RStudio with to.upload2 loaded:
   source("create_database.R")
   ```

3. **Run setup**:
   ```powershell
   .\setup.ps1
   ```

4. **Test the app**:
   ```bash
   npm start
   ```

5. **Build installer**:
   ```bash
   npm run build:win
   ```

### For End Users

1. Run `vFlok Hospital Dashboard-Setup-1.0.0.exe`
2. Follow installation prompts
3. Launch the app from desktop
4. Start using immediately
