🚨 The Problem

The system has two types of campaign IDs getting mixed together:

1. Internal Campaign IDs: Numeric IDs from the 'campaigns' collection (e.g., 213424, 232058)
2. HeyReach Campaign IDs: Long strings from HeyReach (e.g., campaign_1755296493285_patrick_hurban_iqvia.com)

In the heyreach_activity and master_activity_log collections, the campaignId field contains a mix of both types, making reporting inconsistent.

✅ The Solution

  • Store HeyReach campaign IDs in a separate heyreachCampaignId field
  • Look up and store the correct internal campaign ID in campaignId
  • Update all existing records to use the correct structure
