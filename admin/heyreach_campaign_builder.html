HeyReach Campaign Builder

Auto-creates the three standard BDR lead lists (Connect, Message, Quick Message), seeds them with starter contacts (with the critical content custom field mapped), builds the matching campaigns with the standard sequences, sets the schedule, launches them, and associates them to the BDR record used by email_controls.html.

1Customer & BDR

Select the customer workspace (provides the HeyReach API key) and the BDR leader these campaigns belong to.

2LinkedIn Sender Account(s)

The LinkedIn account(s) in HeyReach that will send from these campaigns. Usually just the BDR's own account.

Select a customer to load LinkedIn accounts...

3Starter Contacts (loaded into all three lists)

CSV with headers. Required: First Name, Last Name, LinkedIn Profile URL, content. The content column is mapped to the HeyReach content custom field — this is the critical step that pipes the personalized message into every campaign.

4Messaging & Schedule

Connection requests and messages send {content} (each lead's custom field). If a lead has no content value, the back-up message below is used instead.

5Campaigns to Build

Connect CONNECT

Like recent post → if not connected, send connection request with {content} as the note (auto-withdraw after 21 days) → view profile if not accepted.

Message MESSAGE

Like recent post → if connected, send {content} as a direct message → view profile if no reply.

Quick Message QUICK MSG

If connected, immediately send {content} as a direct message. Used by the Mass Messages tool.
