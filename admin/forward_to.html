How Forwarding Rules Work

  • Email Rules: Specific email addresses are forwarded to designated pages (highest priority)
  • Domain Rules: All users from a domain are forwarded to the same page (lower priority)
  • Priority: Email rules override domain rules. If no rule matches, users go to the default destination
  • Return URLs: If users come from another page, they'll return there instead of using these rules
  • Examples:
    • Domain: clientcompany.com → hospitalpages/client-dashboard.html
    • Email: admin@company.com → admin/users.html
