  • Easy Return: "Exit Impersonation" button to return to admin

How to Use:

  1. Access Admin Panel: Go to admin/users.html with a Pando Executive Networking domain account
  2. Find Target User: Look for the user you want to impersonate in the users table
  3. Click "Sign In As": Click the blue "Sign In As" button next to the user
  4. Confirm Action: Confirm the impersonation in the popup dialog
  5. View as User: You'll be taken to the dashboard as that user
  6. Exit Impersonation: Click "Exit Impersonation" in the red banner to return
Security Notes:
  • Only Pando Executive Networking admins can initiate impersonation
  • All impersonation sessions are logged in the database
  • Users can see when they're being impersonated (red banner)
  • Impersonation data includes admin email and timestamp

Database Collections Created:

  • adminImpersonations - Logs all impersonation sessions
  • users - Updated with lastImpersonatedBy field
