🎯 [sepsis_graphic] Insert - Email-Compatible Sepsis Metrics

Usage: Simply add [sepsis_graphic] to any email template in your Key Benefits messages, and it will automatically generate a beautiful, email-compatible graphic showing sepsis performance metrics.

✨ Key Features:

  • Email Optimized: Uses table-based layout with inline CSS for maximum email client compatibility
  • Low Memory: Lightweight HTML that won't exceed mailto link limits
  • Auto-Generated: Pulls data from organization/contact sepsis fields automatically
  • Color-Coded: Visual indicators (Green = Excellent, Yellow = Average, Red = Needs Work)
  • Professional Design: Clean, modern appearance that looks great in emails
  • Smart Display: Only shows metrics that have data available

Example Email Template:

Hi [first], I wanted to share some insights about [organization]'s sepsis performance metrics: [sepsis_graphic] Based on these metrics, I'd love to discuss how our solution can help improve your sepsis care outcomes. Would you be available for a brief call next week? Best regards

📋 Data Fields Used

The graphic automatically pulls from these fields (from either contact or organization data):

  • sepsis_appropriate_care_percentile - Shows as "Appropriate Care" with 🩺 icon
  • sepsis_lactate_result_percentile - Shows as "Lactate Results" with 🧪 icon
  • sepsis_antibiotic_percentile - Shows as "Antibiotic Timing" with 💊 icon

Note: If no sepsis data is available, the insert will return an empty string (won't show anything).
