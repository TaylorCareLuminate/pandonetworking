Troubleshooting: Why Aren't Tasks Being Created?

1. Railway Server Not Deployed

The recurring tasks processor code must be deployed to Railway. Check Railway dashboard for latest deployment.

2. Schedule is Paused

Check the "Manage Schedules" tab and ensure your schedule status is "Active" (not "Paused").

3. Wrong Time Zone

All times are in UTC. If you scheduled for "3:00", it will run at 3:00 UTC (not your local time).

4. Frequency Conditions Not Met

For weekly schedules, check if today is one of the selected days. For monthly, check the day of month setting.

5. Already Ran This Hour

The system prevents duplicate runs. If a schedule already executed this hour, it won't run again until the next hour.

6. No Organizations Selected

If you selected specific organizations (not "All"), ensure at least one organization is selected.
