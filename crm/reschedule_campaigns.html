Select Campaign
How this works:
  1. Select a campaign with interrupted scheduling
  2. 📧 Choose which BDR accounts to include - only selected accounts will be used
  3. The system analyzes what emails have already been sent
  4. It determines what emails still need to be scheduled
  5. ⏰ Emails are scheduled ASAP - starts 1 hour from now (allows same-day scheduling)
  6. Follow-up emails are spaced 5 days apart using available calendar slots
  7. The same BDR account that started the sequence continues it (if selected)
  8. Duplicate recipients and domains are automatically filtered
  9. 🔒 Slot reservation is MANDATORY - each slot must be successfully reserved before scheduling
  10. If a slot is unavailable, that email is skipped (no double-booking)
