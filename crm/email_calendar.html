How to Fix BDRs with 0 Slots

If a BDR account is showing 0 slots, you need to configure its settings in the Email Controls admin page:

  1. Click the "Configure BDR Settings" button above
  2. Find the BDR account and click "Edit Account"
  3. Set Max Sends Per Day (e.g., 200) and Max Sends Per Hour (e.g., 10)
  4. Ensure "Enable this account" is checked
  5. Assign the account to the correct Customer
  6. Save the account settings
  7. Return here and click "Generate Email Slots (Railway)" to create slots
