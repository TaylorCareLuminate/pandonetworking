Scheduled-Email Cleanup

Delete phantom-sent or failed scheduled-email records so the slots free up for rescheduling.

MAINTENANCE TOOL

READ THIS BEFORE USING

This tool removes scheduledEmails, selfsend_scheduledEmails, and/or sentEmailsDatabase rows for a specific customer in a specific window. It does not unsend any real email. Use it for two cases: (1) Phantom sends — rows marked sent during an outage that were never actually delivered. (2) Failed sends — rows marked failed by the cron that you want to clear so reschedule_campaigns.html can put them back on the calendar. Always scan first, download the CSV backup, and visually verify a sample of rows before deleting.

Orphaned-slot recovery — run this if reschedule_campaigns.html is still pushing days out

Scans email_calendar_slots for the selected customer, finds slots stuck in Reserved with no matching scheduledEmails row, and flips them back to Open. Use this once to clean up after deletes that ran before the slot-release fix existed.
