 Remove Lead from List by Profile URL

            
            

                
 Recommended Method!

                
    
                    
  • Uses Profile URL directly - no need to find HeyReach internal IDs
    • 
                    
  • Deletes leads from a specific HeyReach list/campaign
    • 
                    
  • Can remove multiple leads at once
    • 
                    
  • Returns which profile URLs were not found in the list
    • 
                

            

            
            

                
 What you need:

                
    
                    
  • List ID: The HeyReach list/campaign ID (find this in your HeyReach dashboard URL)
    • 
                    
  • Profile URL(s): The LinkedIn profile URL(s) to remove
    • 
                    
  • Example List URL: https://app.heyreach.io/lists/3672 (3672 is the list ID)
    • 
                

            


            

                

                    
                    
                    
                        Find this in your HeyReach list/campaign URL
                    
                


                

                    
                    
                    
                        If provided, campaign will be paused before removal and resumed after
                    
                


                

                    
                


                

                    
                    
                    
                        Enter one profile URL per line. You can paste multiple URLs at once.

 Working API Endpoints

            
            

                
⭐ Delete Leads from List by Profile URL ✅ RECOMMENDED

                
                    DELETE /proxy/heyreach/lists/deleteleads
                
                
Request:
{
    "listId": 3672,
    "profileUrls": [
        "https://www.linkedin.com/in/john-doe/",
        "https://www.linkedin.com/in/jane-doe/"
    ]
}

Headers:
{
    "x-api-key": "customer_heyreach_api_key"
}

Response:
{
    "notFoundInList": [
        "jane-doe"
    ]
}

                

                    ✅ Why use this:
                    
    
                        
  • Works with profile URLs directly (no need to find HeyReach internal IDs)
    • 
                        
  • Can remove multiple leads at once
    • 
                        
  • Tells you which leads weren't found
    • 
                    

                

            

            
            

                
Get Lead by Profile URL ✅

                
                    POST /proxy/heyreach/leads/getlead
                
                
Request:
{
    "profileUrl": "https://www.linkedin.com/in/john-doe"
}

Headers:
{
    "x-api-key": "customer_heyreach_api_key"
}

Response:
{
    "linkedin_id": "63456789",
    "firstName": "John",
    "lastName": "Doe",
    "fullName": "John Doe",
    "companyName": "Acme Corp",
    "position": "Director",
    "profileUrl": "https://www.linkedin.com/in/john-doe",
    "enrichedEmailAddress": "john@example.com",
    ...
}

            

            
            

                
Remove/Stop Lead ⚠️ (Requires HeyReach Internal ID)

                
                    POST /proxy/heyreach/leads/stop
                
                
Request:
{
    "leadId": "456"
}

Headers:
{
    "x-api-key": "customer_heyreach_api_key"
}

Response:
{
    "success": true,
    "message": "Lead stopped successfully"
}

                

                    ⚠️ Note: This requires HeyReach's internal lead ID, not the LinkedIn ID. Use the profile URL method above instead.
