Rehydrate Timestamps

Find scheduledEmails documents whose sendAt / createdAt / updatedAt were stored as plain-object Maps (a side effect of the CLEmail wrapper before the server-side fix) and rewrite them as native Firestore Timestamps so date queries work again.

ONE-OFF MIGRATION TOOL
What this does: for each scheduled-email row whose timestamp fields are stored as plain Maps (e.g. {seconds, nanoseconds, _isTimestamp:true}), this tool re-writes the row with the same data so the (now-patched) backend stores those fields as proper Timestamps. Nothing is sent, nothing is deleted, no recipients are touched. Always scan first before clicking Fix.
