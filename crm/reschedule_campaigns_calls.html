Campaign Call Rescheduler

Reschedule phone calls for campaigns with interrupted sequences

Select Campaign
How this works:
  1. Select a campaign with interrupted call scheduling
  2. The system analyzes what calls have already been made
  3. Each contact needs 3 calls total, spaced 5 days apart
  4. Calls to the same phone number (shared across contacts) are spaced at least 3 days apart
  5. Contacts with outcomes (scheduled, interested, declined, etc.) are skipped
  6. Contacts with bad phone numbers are skipped
  7. Flagged contacts (pending review) are skipped
  8. Calls are scheduled as soon as possible (today if eligible)
  9. Scheduled calls include timezone data and alternate phone numbers for efficient calling
