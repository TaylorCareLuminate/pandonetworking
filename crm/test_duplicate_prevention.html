🛡️ Duplicate Email Prevention Test

Test the sentEmailsDatabase duplicate prevention for scheduled emails

⚠️ Test Purpose

This test schedules 3 emails to the same contact within minutes of each other to verify the duplicate prevention system works correctly.

Expected Behavior:

  • Email 1: Should send successfully
  • Email 2: Should be BLOCKED (duplicate detected)
  • Email 3: Should be BLOCKED (duplicate detected)

📋 How to Run This Test

  1. Click "Schedule 3 Test Emails" - This schedules 3 emails 1 minute apart
  2. Wait for cron to run - Emails are checked every minute
  3. Click "Check Email Status" - See which emails sent/blocked
  4. Click "View Database Stats" - See duplicate prevention stats
  5. Verify: Only 1 email sent, 2 blocked with failureReason='duplicate_prevention'
