contact_nameFull name of the LinkedIn contact
contact_linkedin_urlNormalized LinkedIn profile URL
contact_titleJob title / position
contact_companyCompany / organization of the contact
bdr_name / bdr_emailWhich BDR sent the outreach
client_companyThe client company this outreach was performed on behalf of
message_typepost / org_news / contact_news / story_search / profile / complement / fast_prospect / about_me_connect / other
first_outreach_dateDate of first outbound message

connected1 if the connection request was accepted, 0 otherwise
connected_by_you1 if the connection request was sent by you/your team and accepted (vs. a pre-existing or inbound connection)
currently_connected1 if this contact is currently a 1st-degree LinkedIn connection, regardless of who initiated it
connection_dateDate the connection was accepted (blank if unknown)
replied1 if the contact sent any reply, 0 otherwise
scheduled1 if the contact scheduled a meeting, 0 otherwise
total_messagesTotal messages in the conversation thread (sent + received)
conversation_historyFull message thread as JSON [{sender, date, text}]
