HeyReach Lead Finder — 5-Method Test

Method 1: GetLead
Not run
Calls /proxy/heyreach/leads/getlead — finds lead anywhere across all HeyReach lists.
Method 2: bdr_leaders Firestore Campaigns
Not run
Loads BDR's heyreachCampaigns from bdr_leaders collection — shows configured campaign IDs & list IDs.
Method 3: GetLeadsFromList (per BDR list)
Not run
Calls GetLeadsFromList with leadProfileUrl filter for each listId from Method 2 — confirms presence in each specific list.
Method 4: GetAllCampaigns → Scan All Lists
Not run
Fetches every campaign via /proxy/heyreach/campaigns/getall, then queries each list — finds which campaign the lead is actually assigned to.
Method 5: heyreach_contacts Firestore
Not run
Queries heyreach_contacts collection in Firestore — checks if this lead was cached locally from HeyReach webhooks.
Combined Trace (Recommended)
Method 6: GetLead → Load BDR Lists → Check Each List
Not run
Confirms the lead exists via GetLead, then loads this BDR's campaign list IDs from bdr_leaders, then calls GetLeadsFromList on each — returns exactly which list the lead is (or isn't) in.
