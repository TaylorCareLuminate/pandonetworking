Organization Finder — Web Search + AI (Test)

Describe the kind of organizations you're looking for (e.g. "employers in Kansas City", "neurology practices in Texas", "hospital systems in the Midwest"). This tool asks an AI model to generate several web search queries, runs them, and has the AI extract a structured list of real organizations from the raw results — with an optional domain, headquarters location, and one-line description for each. It runs multiple expansion rounds (searching for new angles instead of repeating what's already found) to try to reach the number of results you ask for. Use this to explore how large a dataset each model can reliably produce and how accurate it is.
