Auto BDR Connections

Hands-off connection messages between BDRs. A set number of days after a contact connects with one BDR, a second BDR sends them a message that follows your script word for word. Only the name (and any part you mark for the AI) is filled in. A second AI checks every message, and anything that doesn't pass is not sent.

Nightly automation

On
Master switch for the nightly run on Railway (about 1:30 AM Mountain). Turn off to pause every rule at once. Individual rules also have their own switch.
  1. Finds contacts who accepted BDR 1's connection request at least N days ago (and not longer ago than the catch-up window).
  2. Skips anyone BDR 2 is already connected to, has queued, excluded, or that sits at a Do Not Contact organization, plus anyone who declined or was deeply engaged with BDR 1.
  3. Builds ONE message from your script. Fixed text and fields like [First Name] are filled in by code, so the script itself can never be changed. Only a part you put in [square brackets] as an instruction is written by an AI, optionally using a Brave web search.
  4. A second AI reviews the finished message (correct name, nothing invented, reads right). If it doesn't pass, nothing is sent and there is no rewrite.
  5. Passing messages are queued as approved. The regular Connect Queue push then sends them into BDR 2's connect campaign.
