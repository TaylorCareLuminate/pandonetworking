Puts back the “Saw your post about …” details that the ChatGPT clean-up removed from messages still waiting to go out. For each BDR it finds the in-process messages, looks up the original (pre-edit) text, asks Opus to port the post details into the current approved message, lets you review every change, then overwrites the message in HeyReach.

How it works

  1. Scan: for each selected BDR, load the messages still in process (same source as Sent Messages).
  2. Match each to its original message (original_ai_message) and keep only those whose original says “your post” (and whose current text no longer does).
  3. Ask Opus to rebuild the current message with the post details back in, dropping other personalization to make room (275 characters for connection notes).
  4. Review original / current / proposed side by side (edit any proposal), untick what you do not want.
  5. Save: overwrite message_to_contact, push to HeyReach, read it back to confirm, retry failures.
Scope: connection-request records only. Direct / Quick Messages in process are counted and skipped (the server sync does not handle them); use Sent Messages for those. Nothing is changed until you press Save in step 4.
