Queue 1 ↔ Message Variation Batcher

Pick a hypothesis group below and this loads only the connect_queue records that were already sent live — i.e. actually pushed to HeyReach, not just sitting in Queue 1/Queue 2 review — and already belong to that group (matched by tagged contact URL, batch ID, or an existing group stamp). It finds the group's real senders automatically: first it looks up every message anywhere that already carries this group's stamp (from Fast Connect Review), then loads the full send history of every account that appears there — plus the group's recorded BDR(s) and whoever you've checked below — so a stale or incomplete BDR list on the group can't hide messages. It then buckets matches by batch ID (or by send date when no batch ID exists) so you can eyeball a few example messages per batch and assign the right message variation to the whole batch at once. If the match count still looks too low, expand the "Why aren't more matching?" debug panel under the results — it shows real sample URLs from both the group's tagged contacts and the loaded messages side by side, so you can see exactly why.

AI Scan & Auto-Assign Variations

Finds every connection already sent for this group that's missing a variation stamp (or carries one that doesn't match a variation above), reads each message's actual text, and automatically assigns the variation it best matches — using each variation's label, prompt, and example message as the classification rules. This only edits reporting fields on already-sent connect_queue records — nothing gets re-sent — and anything the AI isn't confident about is left alone instead of guessed at.

Import Hypothesis Groups from Document

Paste an outreach strategy document below (any format — campaign briefs, persona breakdowns, messaging matrices). Claude Opus reads it and drafts hypothesis groups with the group name, hypothesis statement, Target Contact / Title Instructions, Message Review Instructions, and message variations. If the document contains reply / follow-up content, it's also extracted as About Me Quick Text Inserts. Everything is shown as an editable preview — nothing is saved until you click "Create Selected Groups".

How grouping works: groups are split by organization type (the kind of company/segment targeted). If a document has several personas at the same type of organization, they become one group with a message variation per persona, each with its own AI Selection Criteria so the right variation is picked per contact. If it has different organization types, those become separate groups — and different personas at those different org types become variations within their respective org-type group.

Quick Text Inserts

Reply / follow-up content found in the document. Checked inserts are added to the About Me profile → Quick Text Inserts of every BDR selected above when you create the groups (existing inserts are kept; duplicates by label are skipped).
