LinkedIn Account Setup with Contact

Meet with BDR to connect their LinkedIn account

Important: This section requires a live meeting with the BDR contact. Schedule a screen-sharing session before proceeding.
1. Log into HeyReach
2. Select the correct company/workspace from dropdown
3. If needed, create new workspace (e.g., Elion)
4. Ensure user has Admin permissions (invite as member if necessary)
Note: Admin options only appear after a company is selected
1. Open the correct workspace
2. In left sidebar, click LinkedIn Accounts (second icon down)
3. Click Connect Account
4. Choose Infinite Login
5. Confirm Two-Factor Authentication (2FA) is enabled
Critical: This step must be completed correctly to avoid connection issues
1. Have user open LinkedIn → Settings & Privacy
2. Go to Sign-in & Security → Two-step verification
3. Confirm the user:
  • Knows their LinkedIn email + password
  • Has their Authenticator app open (not just phone camera)
4. If 2FA is already on:
  • Turn 2FA OFF (LinkedIn will require multiple verifications)
  • Wait ~1 minute
  • Turn 2FA back ON, choosing Authenticator App (not SMS)
1. LinkedIn displays a QR code + manual code
2. User shares the manual code (or scans via authenticator)
3. Screen-share HeyReach and give the LinkedIn user control
4. They enter their LinkedIn credentials into HeyReach
5. Make a note of their email to connect later
6. Submit and keep them on the phone (LinkedIn may send a verification code)
7. Wait until account shows: Purple (syncing) or Green (successfully synced)
1. Confirm the account is fully connected
2. Complete the About Me section (often drafted externally and pasted in)
3. Account is now ready for: Scraping, Messaging, Campaign activity

HeyReach Leads & Campaigns Setup

Import leads and create connection/message campaigns

1. Go to Leads (3rd icon on the left sidebar)
2. Click + Add Leads in the top right
3. Select Import from CSV
4. Upload the connection CSV (download link below)
5. Where it says "Map Custom Email field from:", click + Custom Variable
6. Select content from the dropdown below "Map From"
7. Type content (no caps) in the field to the right
8. Name the list: connect_list_[bdr_name]
Download Connection CSV
Repeat the import process for the message leads list
1. Follow the same steps as above
2. Upload the message CSV (download link below)
3. Map the content custom variable
4. Name the list: message_list_[bdr_name]
Download Message CSV
1. Select Campaigns from 5th icon on the left sidebar
2. Click + Start new campaign
3. Name the campaign: [bdr_name]_connect_campaign
4. Under "Select the list of leads you want to reach out to": Select the connect list you created
5. Select the BDR you want to include in the campaign
1. Check "if connection"
2. Add action: Like the contact's post
3. Add action after minimum time (3 hours): Send message request or Send connection (depending on if connection)
4. Add action: View profile after that
5. Review and launch the campaign
Copy the connection campaign and modify it for messages
1. Find your connection campaign
2. Use the copy/duplicate function
3. Rename to: [bdr_name]_message_campaign
4. Change the lead list to the message list
5. Adjust campaign flow as needed
6. Launch the message campaign

Campaign Settings Configuration

Access the campaign settings page for final configuration
Open Campaign Settings
1. Select the BDR leader from the dropdown at the top
2. Review and adjust:
  • Daily activity limits
  • Message mix preferences

BDR Review Information Setup

Configure target contact and strategy information for the BDR

Define the ideal target contact profile for this BDR to help them stay focused during message review
1. Navigate to the BDR Review Settings page
2. Find the BDR card for [BDR Name]
3. Scroll to the "BDR Review Information" section
4. In the "Target Contact" field, describe:
  • Ideal job title(s) (e.g., "VP of Sales, Chief Revenue Officer")
  • Industry focus (e.g., "Healthcare, SaaS, Enterprise software")
  • Company size (e.g., "50-500 employees" or "Enterprise companies 1000+")
  • Any other relevant targeting criteria
5. Keep it concise but informative (2-4 sentences recommended)
Open BDR Review Settings
Why this matters: This information will be prominently displayed at the top of the Fast Batch Review page to remind the BDR of their target audience while reviewing messages.
Document the current messaging strategy and any important warnings or reminders for the BDR
1. In the same "BDR Review Information" section
2. In the "Current Strategy and Warnings" field, include:
  • Current messaging themes or approaches (e.g., "Focus on ROI and cost savings")
  • Topics to avoid or be cautious about
  • Any compliance or legal requirements
  • Recent feedback or changes to strategy
  • Common mistakes to watch out for
3. Update this regularly as strategy evolves
4. Click "Save Settings" at the bottom of the BDR card
Keep it updated: This field should be reviewed and updated regularly (weekly or monthly) to reflect current strategy, new warnings, or lessons learned.
Pro tip: Use bullet points or short paragraphs for easy scanning. This will appear at the top of the review page alongside the Target Contact information.
Define how the BDR should handle prospect responses, follow-ups, and ongoing conversations
1. In the same "BDR Review Information" section
2. In the "Response Strategy" field, document:
  • How to handle positive responses and interest signals
  • Best practices for follow-up timing and frequency
  • How to address common objections or questions
  • When to escalate or loop in other team members
  • Guidelines for scheduling meetings or demos
  • How to keep conversations warm without being pushy
3. Include specific examples or templates if available
4. Click "Save Settings" at the bottom of the BDR card
Purpose: This field helps the BDR maintain consistent, effective engagement with prospects who respond to outreach messages. Unlike the initial messaging strategy, this focuses on post-response interactions.
Note: This field is for internal reference only and does not appear in the Fast Batch Review interface. It's meant for training and onboarding documentation.

[BDR Name] is now fully configured and ready to start outreach campaigns.
