Dataset Columns

contact_nameFull name of the LinkedIn contact
contact_linkedin_urlNormalized LinkedIn profile URL
contact_titleJob title / position
contact_companyCompany / organization
bdr_nameBusiness Development Rep name
bdr_emailBDR account email
client_companyThe client company Pando Executive Networking is doing outreach on behalf of (the BDR's customer, from customerList — not the contact's own employer)
hypothesis_groupHypothesis group assigned to this contact, or company name if no group is assigned
hypothesis_group_idFirestore doc ID of the hypothesis group (blank if no group is assigned — see hypothesis_group)
hypothesis_variation_idHypothesis sub-group ID — the message variation (A/B test angle) assigned to this contact's message, if any
hypothesis_variation_labelHuman-readable label of the hypothesis sub-group / message variation, if any
connected1 if connection request was accepted, 0 otherwise
connected_by_healthluminate1 if the connection request was initially sent by Pando Executive Networking and accepted. Checks both the heyreach_activity CONNECTION_REQUEST_ACCEPTED webhook AND the connect_queue sent-message log (URL+BDR), since the webhook doesn't always fire/match reliably — if we have a queue record proving we sent the request and the contact is currently connected, it's counted here even without a matching webhook event
currently_connected_on_linkedin1 if this contact is a current 1st-degree LinkedIn connection (from heyreach_contacts), regardless of who initiated the request (catches pre-existing/inbound connections that Pando Executive Networking did not initiate)
connection_dateDate connection was accepted (blank if unknown)
first_outreach_dateDate of first outbound message
first_outreach_sent_atFull date + time (ISO 8601, UTC) the first connection request was actually sent — from the HeyReach message log's own timestamp, not when the contact accepted it (see connection_date) and not just a date like first_outreach_date. Use this to check whether send day-of-week / time-of-day correlates with connect, reply, or meeting rates. Blank if no message-log timestamp or queue timestamp is available.
last_message_dateDate of most recent message in conversation
message_typeThe generation method used to create the outreach message, matching the tabs in generate_messages.html: post (Post Reply) / profile (Profile Message) / about_me_connect (About Me Connect) / org_news / contact_news / story_search / recovered_post / news (generic Internet Search / legacy) / complement (Org Complement) / fast_prospect (Fast Prospect Messaging) / harvest_fast_prospect (Harvest Fast Prospect) / surround_connections (Surround Connections) / other
replied1 if contact sent any reply, 0 otherwise
scheduled1 if contact scheduled a meeting, 0 otherwise
total_messagesTotal messages in conversation thread
bdr_messagesCount of outbound (BDR) messages
contact_messagesCount of inbound (contact) messages
conversation_historyFull message thread as JSON array [{sender, date, text}]
linkedin_connectionsLinkedIn connection count from prospect_contacts (null if not enriched)
follower_countLinkedIn follower count (null if not enriched)
aboutLinkedIn About / bio section (blank if not enriched)
experienceWork experience as JSON array (blank if not enriched)
educationEducation history as JSON array (blank if not enriched)
enriched_atISO timestamp of last profile enrichment (blank if never enriched)
