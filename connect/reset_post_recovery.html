🔄 Reset Post Recovery Flags

Clear messageGenerated flags to allow re-recovery of messages with correct field names

📋 What This Does

This tool resets the tracking flags on worthy LinkedIn posts so they can be re-recovered with the corrected field names.

  • Finds all worthy posts for the selected BDR where messageGenerated = true
  • Sets messageGenerated = false on all those posts
  • Allows you to run recovery again to regenerate messages with proper fields

⚠️ Important Notes

This does NOT delete existing messages. You should manually delete the old messages from Firebase first, then use this tool to reset the flags, then run recovery again.
