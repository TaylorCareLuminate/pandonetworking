BDR Daily Email Summary

Automated daily notifications for time-based message review

Overview

The BDR Daily Email feature automatically sends daily summaries to BDRs who have time-based review enabled. These emails provide a comprehensive overview of all pending messages that will go live after the review period expires.

What's Included in Each Email:

  • Complete Contact Details: Prospect name, title, company, and LinkedIn profile
  • Full Message Content: The exact message that will be sent
  • Message Source: Whether from internet research, LinkedIn posts, etc.
  • Go-Live Date: Exact date and time when the message will be automatically approved
  • Time Remaining: Hours until automatic approval
  • Message Type: Connection request or message to current connection

🎯 Key Features

  • Sends automatically at the BDR's configured time each day
  • Shows all messages pending review with complete details
  • Direct link to review dashboard for easy access
  • Beautiful, mobile-friendly email design
  • Clear visual indicators for urgent messages

Configuration

To enable daily emails for a BDR:

  1. Go to BDR Review Settings
  2. Select a BDR with Time-Based Review mode
  3. In the time configuration section, check "Send daily email summary of pending messages"
  4. Enter the recipient email address (defaults to BDR's primary email)
  5. Set the send time (e.g., 9:00 AM)
  6. Click "Send Test Email Now" to verify the email works
  7. Save the settings
The automated service runs every hour and checks if it's time to send emails based on each BDR's configured send time.

Technical Details

Backend Service:

File: RailwayCLemail/services/bdr_daily_email_service.js
Endpoint: POST /api/bdr/send-daily-emails (manual trigger)
Cron: Every hour at :00 (0 * * * *)

Email Sending:

Endpoint: POST /test-send-daily-review-email
From: noreply@healthluminate.com (or first available account)
Format: HTML with plain text fallback

Database Fields:

bdr_leaders collection:
  - dailyEmailEnabled: boolean
  - dailyEmailRecipient: string (email address)
  - dailyEmailTime: string (HH:mm format, e.g., "09:00")
