Edit in-process messages

Connection notes that were pushed to HeyReach in the last 30 days but have not yet triggered a CONNECTION_REQUEST_SENT webhook — the same cohort as “Still in HeyReach Queue” on the admin dashboard. Edit text in Firestore, optionally rewrite with Llama using [NAME], [FIRST], [ORG], then re-submit to HeyReach so personalization updates in the campaign.

BDR

HeyReach push settings — auto-filled from BDR data; confirm before pushing

Campaign ID, List ID, Account ID, and API key are all auto-filled when you load a BDR. List ID is matched to the exact loaded campaign; Account ID comes from linkedin_accounts; API key comes from the customer record in customerList. All four are required to push.

Filter breakdown

Bulk rewrite (Llama)

Placeholders are substituted before the model runs: [NAME] full name, [FIRST] first name, [ORG] organization (customer name on the queue row when present, otherwise the contact’s company). If Railway has not been redeployed with /api/connect-queue/in-process-llama-draft, this page automatically falls back to /api/connect/diversify-messages (same Llama model; instructions are passed as extra rules; length is capped at 200 chars in that path).

AI Review

Re-pulls each selected contact’s LinkedIn profile via Apify to confirm they’re still at the organization the message assumes, and checks any post/news claim in the message for accuracy. Only flags clear, embarrassing errors — not style or uncertainty. Flagged rows are blocked from saving/pushing until the message is edited or the flag is explicitly overridden. Re-pulling profiles has a small Apify cost (∼$0.001/profile) and may take a minute or two for larger selections.
