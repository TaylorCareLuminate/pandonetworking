Repurpose Messages for a New BDR

Take messages that were researched and written for one BDR and hand them off to a different BDR. Claude Opus checks each message against the new BDR's About Me profile and edits anything sender-specific that wouldn't be true for them — contact-specific personalization is left untouched.

This tool reassigns queued outreach between BDRs and is restricted to admins.
Not Yet Submitted
Messages sitting in the Fast Connect Review queue (connect_queue) that have not been pushed to HeyReach yet. Reassigning these fully switches the sending BDR — the corrected message will go out under the new BDR's LinkedIn account.
In Process in HeyReach
Messages already queued in HeyReach (START → LIKE POST → IS_CONNECTION) that haven't been sent yet. This tool updates the pending message text only — the LinkedIn account already running the sequence keeps sending it (see note below).
Moving an in-process contact to a genuinely different LinkedIn sending account requires pulling it out of the original BDR's HeyReach campaign and re-adding it to the new BDR's — that's a separate, bigger operation and is not done here. This tool only fixes the pending message content in place via HeyReach's API so it no longer misrepresents who's sending it. If the sending account itself must change, use Edit In-Process Messages / Push Contacts for that follow-up step.
