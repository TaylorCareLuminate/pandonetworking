Harvest pool (admin)

Client dashboard (pool progress & outreach) — Track connections that accepted your Connect outreach and have aged into the harvest window (default 30 days). Sub-pools follow the same rules as My Leads filters: target custom groups and optional prospect import batches. Nightly stats run on Railway. Saturday 14:00 UTC queues the harvest pool weekly review for every BDR with at least one harvest pool (Railway cron).

See everyone who should be in your harvest pool

This page shows counts and growth charts by pool. It does not list individual people. To scan and review every connection that is at least your harvest window old (usually 30 days) and tied to accepted Connect activity (plus any manual labels you added), use My Leads:

  1. Open My Leads for the same BDR account.
  2. Under filters, set Harvest pool to “All harvest-eligible (30d+ Connect)”.
  3. Click Apply Filters. The table is everyone currently in your harvest window.

Eligibility uses HeyReach CONNECTION_REQUEST_ACCEPTED dates (same source as message generation). If someone is missing, sync may not have caught them yet—use manual labels below.

Manual harvest labels

Add LinkedIn profile URLs for people you are connected to. Label them as Pando Executive Networking-originated (with the date they connected via our outreach) or Already connected (in your network before / not from HL activity). Optional: assign a sub-pool. Use Bulk import URLs below to paste hundreds at once. Stats refresh after you save (or use Refresh / nightly recompute).

Required for HL. Optional for pre-existing.

Bulk import URLs

Paste hundreds of LinkedIn profile URLs — one per line. You can also separate with commas or semicolons. Blank lines are skipped; duplicates are removed. Uses the same origin, reference date, pool, and notes as the fields above.

Import from HeyReach webhook connections

Scan heyreach_activity for CONNECTION_REQUEST_ACCEPTED in the lookback window. Matches your BDR via bdrEmail and via linkedin_accounts (HeyReach account IDs), same as My Leads / harvest filters — so webhook rows without bdrEmail are still included. Each unique profile gets a manual harvest label (reference date = earliest accept in the window). Choose one pool to assign everyone, or leave default rules.
