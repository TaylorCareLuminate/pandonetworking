Scan Configuration
How to Use — Employee Contact Scanning (click to expand)

The Employee Scan uses LinkedIn via Apify to find contacts at your target organizations. Each scan runs as an individual job — results appear in Active Scan Jobs above as they complete, and contacts are saved to Prospects.

1
Select organizations to scan

Use the All Organizations table above to check individual rows, or use the filter bar + Select ALL Matching Filters to target a large set. The new Select top N input lets you quickly select a fixed number (e.g. 10 or 25) from the current filtered view.

2
Configure your search criteria (this section)

Job Functions — select one or more departments (e.g. Healthcare Services, IT) or leave blank for all departments.
Seniority Levels — narrow to specific levels (e.g. Senior / Director, VP) or leave blank for all levels.
Max Contacts — cap the number of contacts saved per organization (1–2000). 25 is a good default.
Location — optional comma-separated list of states or cities (e.g. Missouri, Texas).
Search Query — keyword filter on LinkedIn profiles; multiple words are AND logic. Use OR between terms for OR logic (e.g. Patient OR Nurse).
Filter Prompt — optional AI pass to exclude irrelevant contacts after LinkedIn returns results.

3
Optional: enable the Second Scan (Fallback)

When the first scan returns fewer contacts than the threshold (default: 5), the system automatically re-runs with the Second Scan criteria — typically broader (e.g. fewer job function filters). This is useful when targeting niche roles that are sparse at smaller organizations.

4
Launch the scan

Click Scan Selected Organizations for Employees to queue one job per selected organization, or Scan Organizations with LinkedIn URLs (Choose Quantity) to auto-pick unscanned organizations that already have a LinkedIn URL. Monitor progress in the Active Scan Jobs section above — each job shows its status, contact count found, and any errors.

Tips
  • Use Saved Presets (panel above) to save search configurations that worked well and reload them for future batches.
  • Give each scan a Batch Name — it appears as a filter in Generate Messages so you can target exactly those contacts.
  • The Scan Count filter in All Organizations helps you find organizations that have never been scanned (0) or ones you've already hit multiple times.
  • If contacts look off (wrong department, too senior/junior), refine using the Filter Prompt field on the next scan.
  • A LinkedIn URL is required for Apify scans. Use Research LinkedIn URLs or Find Missing LinkedIn URLs in the table header first.
