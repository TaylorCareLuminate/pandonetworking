How to use it with ChatGPT

  1. Start a new ChatGPT chat with a model that can read files (Advanced Data Analysis or similar).
  2. Click “Copy ChatGPT prompt”, paste it, and attach the ZIP (or its files).
  3. ChatGPT replies with one JSON object: overall reply instructions plus per client, group and BDR.
  4. Copy that JSON into tab 3 here, review each change, and apply the ones you want.
