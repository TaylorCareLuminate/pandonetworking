Every Apify actor run on this account — with its original input, result dataset, and execution log — so past results can be re-downloaded without re-running (and re-paying for) the actor. This is the same account-wide history behind the Apify console's "Runs" tab.

Only covers Apify-actor pipelines (Harvest, Bebity, ApiMaestro, etc. — anything that shows up under console.apify.com/actors/runs). Tools that skip Apify entirely — like linkedin_url_finder_test.html, which only calls Brave Search + an OpenRouter AI model — won't show up here. For those, results are now auto-saved to Firestore as they run instead.
