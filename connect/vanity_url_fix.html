Vanity URL Fix Utility

Convert non-vanity LinkedIn URLs to vanity URLs in prospect_contacts collection

What this does:
  • Scans all prospect_contacts for non-vanity URLs (contains "ACw" pattern)
  • Uses Apify to fetch the actual vanity URLs for these profiles
  • Updates the linkedInUrl field in Firestore with the vanity URL
  • Processes in batches to respect API limits
