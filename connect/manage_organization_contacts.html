Reconcile Duplicated Batch

Fixes a batch that was moved/duplicated without the duplicate check enabled — including a batch that was split across multiple destination BDRs. For each contact in the batch, on each checked BDR's list: if it already existed there, the pre-existing record is tagged into the batch and the newly-created copy is deleted (nothing stays duplicated). If it's not already there, it's left as the new contact it already correctly is. Contacts on any checked BDR's exclusion list — whichever list they're on — are removed entirely from all of them.
