Organization Filter

Researches each organization via Brave search, then uses the AI model selected above to evaluate if it meets your criteria.

Each line becomes an additional Brave search alongside the general org lookup. [organization name] is replaced with the actual org name before searching.

Combined Title + Organization Filter

Evaluates every unique (title, org) pair as a single holistic judgment. Uses Brave search to research each organization first, then the AI model selected above judges the combination using your rule — which can express relationships like "keep oncology directors anywhere, but only keep general leaders at oncology-dedicated orgs."

Key difference from separate filters: The AI sees the title AND the researched org type together before deciding — so a "VP of Operations" at MD Anderson (oncology-only) can pass while the same title at Mayo Clinic (broad care) does not. Write your rule as a single complete statement rather than two independent checks.

Location / Area Filter

Uses the AI model selected above to evaluate each unique location against your area criteria. Batched for efficiency.

How This Works

This tool scans for contacts that exist in both the prospect_contacts database and the heyreach_contacts (current connections) database. When overlaps are found:

  • The prospect will be marked with category: "Connection" and isConnection: true so it's excluded from message generation
  • The connection will be marked with leadCategory: "Relationship Building Focus" to continue receiving messages
