About This Header

The PandoConnect header provides a beautiful, modern navigation experience across all LinkedIn connection management pages. It automatically integrates with your existing authentication system and provides a consistent brand experience.

How It Works

The header is automatically injected into each page using JavaScript. Simply include the script after auth.js and the header will:

<!-- Load auth.js first for authentication -->
<script src="../js/auth.js"></script>

<!-- Load PandoConnect common header -->
<script src="healthconnect-header.js?v=3.3"></script>
  • ✓ Inject its own styles (no CSS file needed)
  • ✓ Create and insert the header HTML
  • ✓ Connect to Firebase authentication
  • ✓ Update user status dynamically
