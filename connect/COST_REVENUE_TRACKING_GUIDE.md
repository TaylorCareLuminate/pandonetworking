## 🔍 Important: HeyReach Activity Filtering

The system **only counts HeyReach activities from YOUR BDRs**. This is critical because:

- HeyReach webhooks send ALL campaign activities
- We only want to bill for activities WE performed
- The system cross-checks `bdrEmail` field against your BDR list
- Only activities matching a BDR in your system are counted

**How it works**:
1. Load all BDRs from `bdr_leaders` collection
2. Load HeyReach activities
3. Filter activities where `bdrEmail` matches a BDR's `primaryEmail`
4. Calculate costs only for matched activities

1. **`connect_queue`**

## 🛠️ Troubleshooting

### No data showing

**Check**:
- Are there messages in `connect_queue` with `generated_at` dates in your selected range?
- Do messages have `bdr_auth_email` field set?
- Are you filtering by a BDR that has no activity?

**Solution**: Try "All Time" date range and "All BDRs" to see if any data appears.

### Revenue seems low

**Check**:
- Are LinkedIn post and internet search messages being saved with tracking fields?
- Are HeyReach webhooks registered and receiving events?
- Is follow-up tracking implemented?

**Solution**: Check the database directly for messages and verify tracking fields.

### Cost changes not saving

**Check**:
- Console for errors
- Firestore security rules allow admins to write to `settings/cost_revenue_tracking`

**Solution**: Check browser console and Firestore rules.

## 🎓 Key Concepts

### Activity Categorization

Messages are categorized by checking the `generated_via`, `uploadedVia`, or `source` fields:

```javascript
if (source.includes('linkedin_post')) → linkedin_post_message
if (source.includes('internet_search')) → internet_search_message
if (source.includes('profile_message')) → profile_message
if (source.includes('fast_prospect_messaging')) → bulk_group_message
if (source.includes('mass_upload') && !single) → mass_upload_message
if (source.includes('single')) → single_contact_message
```

HeyReach activities are categorized by `eventType`:

```javascript
if (eventType === 'LIKED_POST') → post_like
if (eventType === 'VIEWED_PROFILE') → profile_view
if (eventType === 'CONNECTION_REQUEST_ACCEPTED') → successful_connection
```

### Revenue Aggregation

Revenue is aggregated at two levels:

1. **By BDR**: Groups activities by `bdr_auth_email` or `bdrEmail`
2. **By Company**: Groups activities by `prospect_company` or `leadCompany`

Each group shows:
- Total revenue
- Activity count
- Breakdown by activity type

### Cost Settings Storage

Cost settings are stored in Firestore at `settings/cost_revenue_tracking`:

```javascript
{
  costs: {
    linkedin_post_message: 3.40,
    internet_search_message: 1.10,
    // ... etc
  },
  updatedAt: timestamp,
  updatedBy: "admin@email.com"
}
```

Defaults are used if no settings document exists.
