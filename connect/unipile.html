Unipile Test

Sandbox for evaluating Unipile (API v2) as an alternative to HeyReach for LinkedIn outreach and replies. Pick the connected LinkedIn account, then look up a profile, send a connection request or message, read the inbox and reply, and watch webhooks arrive. Everything goes through the server, so the Unipile API key is never exposed in the browser. Sends are real — they use the selected LinkedIn account.

1. Look up a profile

Unipile needs LinkedIn’s internal user ID (starts with ACo…) to invite or message someone. Paste a profile URL (or just the part after /in/) to convert it. Keep lookups under ~100 per account per day.

2. Send a connection request

For people you are not connected to yet. The note is optional (LinkedIn allows up to 300 characters; free accounts get very few notes per month).

0 / 300
This sends a real LinkedIn invitation from the selected account. Recommended ceiling: ~80–100 invitations/day and ~200/week on a paid account.

3. Message a connection

Starts a new 1:1 chat. LinkedIn only allows this with 1st-degree connections (unless using InMail, which this page does not do). To reply in an existing conversation use the Inbox tab.

Find posts

Paste a LinkedIn post URL, browse your own recent posts, or browse the posts of the person you looked up on the first tab. Then open a post to read its comments, comment, reply to a comment, or like it. Unipile has no webhook for new comments (only messages and new connections), so comment checks are manual — avoid frequent polling. Keep other actions to roughly 100/day per account.

Register webhooks

Webhooks are how Unipile tells us about replies and accepted invitations in real time. This registers our test receiver (below) with Unipile. Each delivery is checked against Unipile’s HMAC signature before it is accepted, and shows up in the live list further down.
