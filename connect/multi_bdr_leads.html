Bulk Group Assignment

Work on several BDRs in one visit, but one BDR at a time for ChatGPT. Pick the BDRs, and each BDR gets their own Excel file (with each person's experience and education where we have it, and only the hypothesis groups that BDR can use). Give each file to ChatGPT in its own chat to sort the contacts into groups, then load the JSON it returns into that BDR's own upload box. Contacts are only ever put into a group their own BDR is associated with.
