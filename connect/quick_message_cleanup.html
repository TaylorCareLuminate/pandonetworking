Quick Message Cleanup

Find contacts submitted to a BDR's Quick Message campaign more than N days ago, then remove them from HeyReach (stop + purge from list) so they're eligible for re-messaging later.

This scans the same tracking data (quick_message_campaign_leads) used by the automatic nightly Railway cleanup job. Only contacts added via a Quick Message tool (Mass Messages to Connections, Campaign Follow-up, Fast Batch Review, etc.) are tracked here — contacts added directly in HeyReach won't show up.
