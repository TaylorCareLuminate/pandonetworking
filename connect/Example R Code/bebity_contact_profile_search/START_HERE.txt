FUNCTION PARAMETERS

bebity_company_search(
  organization_names,        # REQUIRED: character vector of org names
  limit = 5,                 # Number of results per org (default: 5)
  apify_token = NULL,        # API token (default: env var APIFY_API_KEY)
  cache_dir = "...",         # Cache directory (default: standard location)
  force_refresh = FALSE,     # Ignore cache and search anyway
  use_gpt_matching = TRUE    # Use GPT for smart name matching
)


WHAT YOU GET BACK
═════════════════

Data frame with these columns:

• search_query: Your original search term
• organization_name: Organization name found on LinkedIn  
• linkedin_url: LinkedIn company page URL
• search_date: Date when search was performed
• is_cached: TRUE if from cache, FALSE if new search
• match_confidence: "cached", "new_search", or GPT score


ADVANCED FEATURES
═════════════════

1. Force Refresh
   # Ignore cache, always do fresh search
   bebity_company_search("Mayo Clinic", force_refresh = TRUE)

2. Disable GPT Matching (faster but less smart)
   bebity_company_search("Mayo Clinic", use_gpt_matching = FALSE)

3. More Results Per Search
   bebity_company_search("Memorial Hospital", limit = 10)

4. Custom Cache Location
   bebity_company_search("Mayo", cache_dir = "C:/My Cache")


TECHNICAL NOTES
═══════════════

• Uses bebity/linkedin-premium-actor Apify actor
• Action: "get-companies" (searches for company pages)
• Cache grows automatically over time
• Thread-safe for parallel processing
• Handles API errors gracefully
• Falls back to base R save/load if saver/loadr not available
• Falls back to exact matching if gpt.batch not available
