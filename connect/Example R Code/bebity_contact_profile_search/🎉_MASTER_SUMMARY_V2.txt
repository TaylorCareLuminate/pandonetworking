PART 1: WHAT YOU REQUESTED
═══════════════════════════════════════════════════════════════════════════════

YOUR REQUIREMENTS:
─────────────────
1) System runs through each organization one at a time ✅
2) System searches for organization's LinkedIn URL in saved data ✅
3) If not found, profile URL is searched with bebity API ✅
4) After all orgs searched, gpt.batch verifies matches ✅
5) For unmatched, gemini.batch generates alternative names ✅
6) Each alternative is searched again using bebity ✅
7) Third round uses gemini.batch and bebity for final attempt ✅
8) All findings saved in database for later searches ✅


WHAT I BUILT:
────────────
A sophisticated 3-round search system that progressively gets smarter:

ROUND 1: Cache Check + Initial Search
• Checks cache for exact matches
• Searches Apify for unfound organizations
• Saves all results to cache

ROUND 2: Intelligence Layer
• GPT verifies ALL found matches (gpt.batch)
• Gemini generates 2-3 alternative names for unfound (gemini.batch)
• Searches each alternative via Apify
• Saves results linked to original query

ROUND 3: Final Attempt
• Gemini generates ONE best search term for remaining unfound (gemini.batch)
• Final Apify search attempt
• Saves any results to cache

RETURNED DATA FRAME:
───────────────────
• search_query: Your original search term
• organization_name: Organization name found on LinkedIn
• linkedin_url: LinkedIn URL
• search_date: Date found
• search_round: Round that found it (1, 2, or 3)
• match_confidence: Verification method
  - "gpt_verified": GPT confirmed match
  - "gemini_alternative": Found via Gemini alternative
  - "gemini_final": Found in final Gemini attempt
  - "round1_direct": Direct Round 1 match
  - "cached": From cache
• is_cached: TRUE if from cache, FALSE if new

CUSTOMIZATION OPTIONS:
─────────────────────
```r
# Fast mode (Round 1 only, no AI)
bebity_company_search(orgs, max_rounds = 1, use_gpt_verification = FALSE)

# No Gemini (GPT verification only)
bebity_company_search(orgs, use_gemini_alternatives = FALSE)

# Silent mode
bebity_company_search(orgs, verbose = FALSE)

# Force refresh (ignore cache)
bebity_company_search(orgs, force_refresh = TRUE)

# More results per search
bebity_company_search(orgs, limit = 10)
```
