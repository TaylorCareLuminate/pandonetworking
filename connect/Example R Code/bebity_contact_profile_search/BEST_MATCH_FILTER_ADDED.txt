NEW PARAMETER: return_best_match_only
══════════════════════════════════════

I've added a new parameter to bebity_company_search() that solves the multiple 
matches problem!


THE PROBLEM YOU HAD
═══════════════════

When searching for "Arrowhead Regional Medical Center", you got 4 results:
1. Arrowhead Regional Medical Center (main - gpt_verified)
2. Arrowhead Regional Medical Center Foundation (gpt_mismatch)
3. Arrowhead Regional Medical Center Behavioral Health (gpt_verified)
4. Medical Staff of the Arrowhead Regional Medical Center (gpt_mismatch)

You only wanted #1 (the main organization)!


THE SOLUTION
════════════

NEW PARAMETER: return_best_match_only = TRUE

When enabled, the function:
1. Completes all search rounds normally
2. Identifies organizations with multiple matches
3. Uses gpt.batch to select the BEST match
4. Returns only ONE LinkedIn URL per organization


HOW IT WORKS
════════════

For each organization with multiple matches:

1. GPT receives a prompt like:
   "I'm searching for the LinkedIn company page for 'Arrowhead Regional Medical Center'.
    Here are the options I found:
    
    (1) Arrowhead Regional Medical Center - linkedin.com/company/arrowhead-...
    (2) Arrowhead Regional Medical Center Foundation - linkedin.com/company/...
    (3) ARROWHEAD REGIONAL MEDICAL CENTER BEHAVIORAL HEALTH - linkedin.com/...
    (4) MEDICAL STAFF OF THE ARROWHEAD REGIONAL MEDICAL CENTER - linkedin.com/...
    
    Which option is the BEST match for the main organization (not foundations, 
    departments, or affiliates)? Reply with ONLY the number."

2. GPT responds: "1"

3. Function selects option #1 and marks it as "gpt_best"

4. Other options are discarded


USAGE
═════

DEFAULT (returns all matches):
```r
results <- bebity_company_search(c("Mayo Clinic", "Arrowhead Regional"))
# Returns multiple matches per organization
```

WITH FILTER (returns best match only):
```r
results <- bebity_company_search(
  c("Mayo Clinic", "Arrowhead Regional"),
  return_best_match_only = TRUE  # ← NEW!
)
# Returns ONE match per organization
```

MATCH CONFIDENCE UPDATED
════════════════════════

When GPT selects the best match, the match_confidence field is updated:

Original: "gpt_verified"
Updated:  "gpt_verified_gpt_best"

This tells you:
• "gpt_verified" = GPT confirmed it matches your search
• "_gpt_best" = GPT selected this as the best option among multiple
