Rescue Untagged Scan Contacts TEMP TOOL

Finds contacts that a completed Full Pipeline scan job saved to a BDR's prospect_contacts but that never got tagged into the hypothesis group the scan was run for (the run stopped or errored between the scan and the tagging step). They're already paid for — this puts them back where they belong. Each contact goes through the group's Target Contact / Exclude Rules exactly as the pipeline would have (rule-drops are archived to prospect_contacts_deleted), already-connected people are skipped, and the keepers are tagged into the group and added to its contact list so Generate Messages sees them.

Run the dry run first — it tells you how many untagged contacts exist per group and BDR. Then untick "Dry run" to apply. In a dry run the rules are not applied (no AI cost), so the "would be rescued" number is before the rules filter. Safe to re-run: it only ever touches contacts that are still untagged.
