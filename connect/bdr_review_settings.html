How Review Modes Work

  • Auto-Approve (Immediate): Messages are automatically approved and ready to push immediately after admin review. BDR review is skipped entirely.
  • Manual Review: BDR must explicitly approve every message before it can be pushed to HeyReach. Messages wait indefinitely until approved.
  • Time-Based Review: BDR has a set number of hours to review and edit messages. After the review period expires, messages are automatically approved and can be pushed.
  • Queue 1 (Admin): Admins review content quality and appropriateness
  • Queue 2 (BDR/Customer): BDRs review messages for their specific prospects - these settings control Queue 2 behavior

What does this do?

Purpose: The last_internet_search_date field tracks when each prospect was last searched using internet news. Prospects are only eligible for internet search if this field is null or older than 7 days.

Reset All: Removes last_internet_search_date from ALL prospects in the database, making them all eligible for internet search.

Reset for Specific BDR: Removes last_internet_search_date only for prospects assigned to a specific BDR.

Note: This does NOT affect LinkedIn post search tracking (last_search_date), which is tracked separately.
