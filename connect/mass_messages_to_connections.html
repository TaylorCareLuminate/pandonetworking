Generation Options

🔀

Vary Messages

Add slight phrasing variations to each message so they don't look identical — better for deliverability and naturalness.

💬

Tailor to Past Conversations

Searches this BDR's conversation history with each contact. Where a prior exchange exists, the AI tailors the message to acknowledge it naturally.

🔍

Enrich with Profile Data

Pulls each contact's LinkedIn profile from the local cache first. If not cached (<90 days), fetches via Apify. Uses Apify credits for uncached contacts.

📰

Include AI Searched News Intro

Searches for recent positive news about each contact's company (past 3 months via Gemini + Google Search). If found, prepends a warm opener sentence referencing the news — e.g. "Saw the news about…"
