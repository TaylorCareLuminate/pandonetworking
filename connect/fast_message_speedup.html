Fast Message Speed-Up

Messages waiting in a BDR’s Quick Message HeyReach campaign can go out faster when the contact already has an open HeyReach conversation. This page finds those messages, then moves them out one at a time: it removes the lead from the Quick Message campaign, confirms it is really gone, and sends the same text through the existing conversation. A random 60–180 second pause runs between each one.

1 Find messages that can use a conversation

The scan reads the Quick Message campaign live from HeyReach (messages not yet sent, paused, or failed), then asks HeyReach right now whether each contact has an open conversation on the campaign’s LinkedIn account. Only the message text (the campaign’s content field) is sent through the conversation.
