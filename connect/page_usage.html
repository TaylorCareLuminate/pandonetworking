Rough estimate of hours spent in Connect, per person.
How this is estimated
  • Each person's page visits are put in time order. Time on a page runs from when it was opened until they opened the next page.
  • If the next page was opened within 20 minutes, the whole gap is counted. If it was longer, only 20 minutes are counted, since they probably walked away.
  • The last page of the range has no "next page", so it adds no time. Someone with a single visit shows 0.
  • Uses the time range and person selected above. The page search box is ignored, so time isn't lost when you filter pages.
