Search Configuration

How Keyword Search Works

Enter keywords to search LinkedIn for professionals with matching services or expertise. The search will find profiles and upload them directly to your BDR account.

  • Keywords: Search terms like "Employee Benefits", "HR Consulting", etc.
  • Location filter: Optionally restrict results to specific locations (e.g. "United States"). Passed directly to the Apify actor — LinkedIn's location autocomplete is used, so use full names ("United Kingdom" not "UK").
  • Results per Search: Number of contacts to find (up to 2500, 25 per page)
  • Resume support: After each job the backend saves the actual last page Apify returned. Re-type the same keyword to see the purple resume banner and start from where you left off.
  • Single source of truth: Contacts are saved to prospect_contacts with linkedInConnectionCount, about, experience, and education. If the contact already exists, their record is updated rather than duplicated.

Batch Multi-Keyword Search

How Batch Search Works

Add multiple keywords below — each with its own contact target. When you click Submit All, one independent search job is created per keyword (just like the single search above), and all results are saved to the same BDR or Workspace selected at the top.

  • Each keyword runs as a separate Apify job — they may run in parallel on Railway.
  • A shared location filter and start page apply to every keyword in the batch.
  • Set target contacts to 0 for unlimited (runs until Apify has no more results).
  • After submission each job appears in Search Sessions above, where you can monitor, continue, or re-run it.
