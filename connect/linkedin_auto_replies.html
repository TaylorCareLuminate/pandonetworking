LinkedIn Auto-Replies

Detects generic LinkedIn solicitations in your inbox and drafts a decline + personalized pitch example. Manual only — nothing is ever sent automatically. Click "Run Now" to draft candidates, review each one below, then click "Send" per item you approve. This view defaults to showing only Queued items — those are the only ones that can ever be sent. Anything under Skipped (test messages, known contacts, already-personalized outreach, etc.) has no draft reply and no Send button — it is not, and cannot be, sent.

No CareLuminate BDRs are configured for auto-reply.

Before running a scan, enable the feature for at least one customer in Email Controls → edit a customer → check "Enable automated LinkedIn inbox replies." Then return here and use Run Now with a back-scan to catch historical messages.

Run Auto-Reply Scan

Scan your LinkedIn inbox for new inbound solicitations and draft a personalized counter-pitch reply for each one. This never sends anything. Every result is queued below for you to review and click "Send" individually — there is no automatic/scheduled run anymore.

Set a number to scan for messages received in the last N days that haven't been processed yet. Leave blank to process only new messages.
