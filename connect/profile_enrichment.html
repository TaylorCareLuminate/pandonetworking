Step 1: Configure Scan

How it works:
  • Select whether to scan Current Connections (heyreach_contacts) or Prospects (prospect_contacts)
  • Choose which missing fields to look for (name, job title, company, email)
  • Click Scan to see which contacts have gaps
  • Then run enrichment — Bebity scrapes LinkedIn profiles and fills in the missing data
Filter by Batch (optional)
Use Import Batch to target a specific scan/import run, Move Batch for contacts moved from another BDR, or Group Batch for custom groups. Setting multiple filters applies all simultaneously.
Workspace:

Scanning and enriching contacts in this workspace. Contact type is locked to Prospects (prospect_contacts).

Fields to check for missing data

LinkedIn Engagement Score (0–100)

Bebity scans each LinkedIn profile and scores it based on two signals:

Premium Account
0 – 30 pts
+30 if the contact has a LinkedIn Premium badge.
Indicates higher investment in professional networking.
Content Activity
0 – 70 pts
Based on volume of posts & articles returned by Bebity:
1–5 items → 15 pts  ·  6–15 → 35 pts
16–30 → 50 pts  ·  31–50 → 60 pts  ·  51+ → 70 pts

When Engagement Score is the only field selected, contacts that have any missing field (name, title, company, or email) and a LinkedIn URL will be scanned and scored. The score is saved as linkedInEngagementScore in Firestore.

Sets limit to 50 and scans immediately — great for testing.

Move Batch to Another BDR

Reassign all contacts from a specific import batch (sourceJobId) to a different BDR. This updates the userEmail, bdrEmail, and linkedInAccountEmail fields on every contact in that batch.

Connection Count Probe Diagnostic

What this does: Fetches up to 10 LinkedIn profiles via the Bebity scraper and checks whether the raw response includes a connections count field. This determines whether we can use connection count as a filter in generate_messages.html (require ≥ 250 connections before generating messages for a prospect).

Uses the same Contact Type and BDR / Workspace filters from Step 1 above. All raw field data is logged so you can see exactly what Bebity returns.
Max 20 — each profile is one Bebity API call
