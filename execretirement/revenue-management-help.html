Revenue Management Help Guide

Complete guide to managing revenue data in Executive Retirement Solutions

Overview

The Revenue Management system allows you to track, analyze, and report on all plan revenue across your business. The system integrates data from multiple sources and creates a unified enriched dataset for comprehensive reporting.

Manual Entry

Input plan data and record keeper information directly

CSV Import

Bulk import plan revenue data from Excel/CSV files

Direct Import

Import contract data directly from record keepers

PensionPro Sync

Automatically sync client and plan data from PensionPro

Data Input Methods

Manual Entry

You can manually create and edit plan revenue data at any time:

  • Record Keepers: Navigate to "Record Keepers" to add or manage record keeper providers
  • Plan Data: Use "Import Excel Data" or "Plan Revenue Detail" to add new plans
  • Edit Plans: Click on any plan in "Plan Revenue Detail" to view and edit all fields
  • Incomplete Plans: Use "Incomplete Plans" page to fill in missing data

CSV/Excel Import

Import bulk plan data from spreadsheets:

  • Navigate to "Import Excel Data" in Revenue Management
  • Upload your CSV file containing plan information
  • System validates data and identifies any incomplete records
  • Match plans to existing record keepers or add new ones
  • Import creates plans marked as 'complete' or 'incomplete' based on data availability
Important: All plans are imported regardless of completeness. Incomplete plans are flagged for later completion and can be found on the "Incomplete Plans" page.

Direct Record Keeper Import

Import contract data directly from record keeper platforms:

  • Navigate to "Direct Import" under Direct Record Keeper section
  • Upload contract data files from your record keeper (e.g., Fidelity, Vanguard, etc.)
  • System parses contract details including asset values, fees, and participants
  • Use "Data Reconciliation" to match record keeper contracts with your internal plan data
  • Matched data provides accurate asset and revenue information

PensionPro Data Integration

Automatically sync client, plan, advisor, and project data from PensionPro:

  • Navigate to "PensionPro Data Import" under PensionPro Integration section
  • System automatically fetches data from PensionPro API on page load
  • Data includes: clients, plans, advisors, projects, and statuses
  • System auto-matches PensionPro data to your revenue plans using fuzzy matching
  • Review and confirm matches, or manually search for plans
  • Multiple PensionPro plans can be matched to a single revenue plan
  • Match table is saved to Firebase for future use
Note: PensionPro status data will automatically overwrite your revenue data status in the enriched dataset when available. Original revenue data remains unchanged.

Data Enrichment Process

The enrichment process combines data from multiple sources to create a comprehensive dataset for reporting and analysis.

Base Revenue Plans Data
(ers/revenue_plans)
↓
Record Keeper Contract Data
(when matched via reconciliation)
↓
PensionPro Data
(when matched via PensionPro import)
↓
Enriched Revenue Plans
(ers/enriched_revenue_plans)

Enrichment Steps

1

Base Data Foundation

ALL revenue plans are ALWAYS included in the enriched dataset, regardless of whether additional data is available. Every plan from ers/revenue_plans is copied with all its fields intact.

2

Record Keeper Data Integration

If a plan has been matched to a record keeper contract (via Data Reconciliation), accurate asset values, participant counts, and fee information are added. These values override internal estimates.

3

PensionPro Data Enhancement

If a plan has been matched to PensionPro data, 26+ additional fields are added with 'pp_' prefix including client info, plan details, advisor information, and project data.

4

Status Overwrite

When PensionPro data includes a status (Active, Onboarding, Terminated), it overwrites the revenue status in the enriched dataset. Original revenue data remains unchanged.

5

Enriched Dataset Created

Final enriched dataset contains ALL plans. Some have record keeper data, some have PensionPro data, some have both, some have neither. All are included and valid.

Data Protection: The enrichment process NEVER modifies your original revenue data (ers/revenue_plans) or PensionPro data. The enriched dataset (ers/enriched_revenue_plans) is a read-only combination used for reporting.

Triggering Enrichment

The enriched dataset is rebuilt in these scenarios:

  • Data Reconciliation: After confirming record keeper matches, click "Build Enriched Dataset"
  • PensionPro Import: After confirming PP matches, click "Confirm Matches & Enrich Dataset"
  • Plan Edits: When you edit a plan in "Plan Revenue Detail", the enriched record is automatically updated
  • Incomplete Plans: After completing plans, click "Rebuild Enriched Dataset With Updates"

Reporting & Analytics

All reporting and analytics pages pull data from the enriched dataset, giving you the most complete and accurate view of your revenue.

Revenue Dashboard

High-level overview of total revenue, assets, and key metrics

Revenue Analytics

Deep dive into revenue by year, record keeper, admin, and business unit

Plan Revenue Detail

Detailed view of all plans with revenue calculations and editing

Keeping Reports Current

To ensure your reports reflect the latest data:

  • Rebuild the enriched dataset after importing new data
  • Re-run reconciliation when you have updated record keeper files
  • Refresh PensionPro data periodically to get current statuses
  • Individual plan edits automatically update the enriched dataset

Best Practices

Recommended Workflow

  1. Import Base Data: Start by importing your plan revenue data via CSV or manual entry
  2. Complete Missing Data: Use "Incomplete Plans" to fill in any missing information
  3. Add Record Keeper Data: Import record keeper contract data and reconcile matches
  4. Sync PensionPro: Match PensionPro data to enhance with client and project details
  5. Build Enriched Dataset: Trigger enrichment to combine all data sources
  6. Review Reports: Check analytics and dashboards for insights
  7. Maintain Regularly: Update data monthly or quarterly to keep reports accurate

Tips for Success

  • Always use consistent naming for clients and plans across systems
  • Match confidence scores above 85% are typically accurate auto-matches
  • Review "Needs Review" matches carefully before confirming
  • Save match tables so you don't have to re-match every time
  • Check the console logs for detailed enrichment information
  • PensionPro status data is considered the "source of truth" for plan status
